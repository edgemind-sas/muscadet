# Failure modes

A failure mode declared on a component is a method of `ObjFlow`
(`add_exp_failure_mode`, `add_delay_failure_mode`, `add_atm2states`): see
[Components](components.md). A standalone mode, declared as a component of its
own over several targets, is a `cod3s.ObjFM*` or a `cod3s.ObjMode2S`. What
MUSCADET adds to it is the publication below.
